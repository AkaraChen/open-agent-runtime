# Benchmark 总结：优化后（合并 PR #3）对比优化前（第 0 步基线）

> 本报告由 `hack/bench` 自动生成，原始数据见同目录的 `results-*.json`；括号里的变化是相对**第 0 步基线**（[00-baseline](../00-baseline/README.md)，开始优化之前），不是相对上一步。新增的指标没有括号。

合并 PR #3（commit `79a0736`）之后，在 main 上跑的完整 benchmark，用来对比全部优化前后。各步骤做了什么见 [benchmarks/README.md](../README.md)。

注意：
- 基线里 vz 的「空闲内存 19.6 MiB」是测量错误（当时没算 Virtualization.framework 的 XPC 进程），之后才修正；它不是回归。
- 增量 warm 和冷 warm 变慢是有意的取舍：warm 现在要建硬链接视图，并在结束前刷盘，换来首次启动不再有长尾。
- kvm 容器内 TCP 建连（`net.connect`）从基线的 2.9 ms 变为 9.1 ms，出现在第 6 步（改用 microvm 机型）之后，尚未处理。
